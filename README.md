# Tennis Career

A Python package for retrieving tennis career match data from
Tennis Abstract and plotting match outcomes by player age and
age difference with opponents.

## Planned public functions

- `get_career_matches(player_name)`: retrieve and clean career match data.
- `plot_career_matches(matches)`: plot the cleaned match data.

## Development plan

- Create an installable Python package.
- Parse career JavaScript data using local test fixtures.
- Handle opponent birth dates and opponent ages.
- Retrieve player data with meaningful error messages.
- Reproduce the HW2 scatter plot for different players.
- Document installation and usage.

Automated tests will use local fixtures without contacting live servers.
